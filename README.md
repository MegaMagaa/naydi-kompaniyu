# Найди компанию

Учебный веб-проект: сервис для поиска людей для совместных занятий по интересам и времени.

## Возможности

- Регистрация и вход пользователей.
- Создание встреч с категорией, датой, временем, форматом и количеством мест.
- Лента активных встреч и фильтры по категории, формату и поисковому запросу.
- Просмотр карточки встречи и списка участников.
- Присоединение к встрече и выход из неё.
- Закрытие встречи её создателем.
- Личный кабинет со встречами пользователя.
- Отправка жалоб на встречи.
- Пароли хранятся в виде хешей, а не открытым текстом.

## Что используется

- Python и Flask — серверная часть.
- SQLite — база данных (создаётся автоматически при первом запуске).
- HTML, CSS — страницы и оформление.

Выбрана связка Flask + SQLite, потому что она достаточно простая для первого самостоятельного учебного проекта и не требует отдельного сервера базы данных.

## Запуск на Windows

1. Установи Python 3.10 или новее с сайта https://www.python.org/downloads/.
2. Распакуй архив проекта.
3. Открой папку `naydi_kompaniyu`.
4. В адресной строке Проводника набери `cmd` и нажми Enter.
5. Создай виртуальное окружение:

   ```bash
   py -m venv .venv
   ```

6. Активируй его:

   ```bash
   .venv\Scripts\activate
   ```

7. Установи зависимости:

   ```bash
   pip install -r requirements.txt
   ```

8. Запусти сайт:

   ```bash
   python app.py
   ```

9. Открой в браузере адрес http://127.0.0.1:5000.

## Запуск на macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

Затем открой http://127.0.0.1:5000.

## Первый запуск и данные

Файл `app.db` создаётся автоматически рядом с `app.py`. Чтобы начать с чистой базой, останови сервер и удали `app.db`, затем снова запусти приложение.

## Важные замечания

Это учебный прототип, предназначенный для локального запуска и демонстрации. Не публикуй его в открытом интернете без дополнительной проверки безопасности. Перед реальным запуском нужно настроить секретный ключ, защиту от CSRF, ограничение частоты запросов, подтверждение аккаунтов, модерацию жалоб, резервное копирование и HTTPS.

Для очных встреч приложение просит указывать общественное место, а не домашний адрес. Не публикуй личные контакты или точное местоположение. Для учебной демонстрации безопаснее использовать вымышленные данные и тестовые аккаунты.
